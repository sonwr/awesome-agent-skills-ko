# Contributing

Thanks for contributing to `awesome-agent-skills-ko`.

## Principles

- Prefer practical impact over novelty.
- Keep instructions reproducible.
- Explain tradeoffs and limitations.

## Pull request requirements

Include in every PR:

1. What problem this solves
2. Setup steps
3. Expected output
4. Validation steps
5. Known limitations

## Review checklist

- [ ] Clear purpose
- [ ] Reproducible instructions
- [ ] Validation included
- [ ] Limitations documented
- [ ] No vendor lock-in assumptions hidden
