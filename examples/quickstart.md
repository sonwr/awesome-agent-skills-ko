# Quickstart Example

README에서 바로 이어서 보려면 `README.md`의 **처음 5분 기여 흐름 / first 5-minute contribution flow**를 먼저 읽고 이 예시로 내려오세요.
English mirror: If you came from the README, follow the **first 5-minute contribution flow** first, then use this quickstart as the copyable execution step.

1. Pick a skill/template category.
2. Follow setup exactly.
3. Run validation.
4. Record results and limitations.

## Copyable first command

```bash
python3 templates/scripts/validate_template.py
```

## Next reading step

- 한국어: 검증이 끝나면 `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md`로 돌아가 최소 증빙 3종(명령/종료코드/핵심 출력)을 PR 코멘트에 남깁니다.
- English mirror: After validation, return to `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md` and paste the three minimum evidence items (command / exit code / key output) into the PR comment.
