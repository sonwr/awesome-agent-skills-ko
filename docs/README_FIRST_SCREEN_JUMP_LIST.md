# README 첫 화면 바로가기 / README first-screen jump list

README 상단에서 처음 방문자가 가장 먼저 클릭해야 할 핵심 이동 경로를 짧게 정리한 문서입니다.
English mirror: A compact jump-list reference for the first clicks a newcomer should see near the top of the README.

## 한국어 기준 / Korean-first jump list
- 프로젝트 소개
- 대상 사용자
- 제공 가치
- 대표 카테고리/활용 시나리오
- 빠른 시작 명령
- 운영 문서 핸드오프

## English mirror
- Project overview
- Target audience
- Immediate value
- Featured categories / use cases
- Quick-start command
- Governance handoff

## 유지 규칙 / Maintenance rule
README 첫 화면을 수정할 때는 소개 -> 대상 사용자 -> 제공 가치 -> 대표 예시/카테고리 -> 빠른 시작 -> 운영 문서 핸드오프 순서를 깨지 않는지 함께 확인합니다.
English mirror: When editing the README first screen, preserve the order intro -> audience -> value -> featured examples/categories -> quick start -> governance handoff.
