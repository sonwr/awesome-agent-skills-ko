# README 프로젝트 소개·가치·빠른 시작 원페이지 / README project intro, value, and quick-start one-pager

README 상단을 고칠 때 가장 먼저 맞춰야 하는 소개형 압축본입니다.

- **프로젝트 소개** — 한국어 기반 빌더를 위한 에이전트 스킬 큐레이션 + 실행 가능한 템플릿 모음
- **대상 사용자** — 한국어 기본 흐름으로 탐색·검증·기여를 빠르게 시작하려는 개인/팀
- **대표 가치** — 첫 화면에서 프로젝트 소개, 대표 카테고리, 첫 검증 명령, 다음 문서를 바로 찾게 함
- **대표 예시/카테고리** — `examples/quickstart.md`, `examples/pr-evidence-mini-walkthrough.md`, `docs/CURATION_POLICY.md`
- **빠른 시작** — `python3 templates/scripts/validate_template.py` 실행 후 `examples/quickstart.md`로 이동

English mirror:
A compact reference for editing the README landing area without losing the project-first structure.

- **Project intro** — a curated, practical collection of agent skills and runnable templates for Korean-speaking builders
- **Who it helps** — individuals and teams who want fast Korean-first discovery, validation, and contribution flows
- **Immediate value** — make the project intro, featured categories, first validation command, and next document visible from the first screen
- **Featured examples/categories** — `examples/quickstart.md`, `examples/pr-evidence-mini-walkthrough.md`, `docs/CURATION_POLICY.md`
- **Quick start** — run `python3 templates/scripts/validate_template.py`, then open `examples/quickstart.md`

## 사용 시점 / When to use it

- README 첫 40~120줄을 재배치할 때
- 소개/가치보다 운영 문서가 위로 올라오지 않는지 확인할 때
- 기여 규칙을 아래로 내리고도 첫 실행 동선을 유지해야 할 때

- When rearranging the first 40-120 lines of the README
- When checking that governance links do not rise above intro/value cues
