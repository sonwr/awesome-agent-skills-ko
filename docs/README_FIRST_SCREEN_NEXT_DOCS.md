# README 첫 화면 다음 문서 카드 / README first-screen next-docs card

README 첫 화면을 읽은 직후, 방문자가 바로 열어야 하는 다음 문서를 짧게 고정하는 기준 카드입니다.
This card keeps the immediate next docs explicit after the first README screen.

## 한국어 기준 / Korean-first rule

첫 화면에서는 프로젝트 소개, 대상 사용자, 제공 가치, 빠른 시작을 먼저 보여주고,
그 직후에는 아래 세 문서 중 하나로 자연스럽게 이어져야 합니다.

1. `examples/quickstart.md` — 바로 실행하고 싶은 사람
2. `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md` — 첫 PR 증빙이 필요한 사람
3. `docs/README_FAST_PATHS.md` — 운영/정보구조를 점검하려는 사람

## English mirror

After the first README screen, the next document should be obvious:

1. `examples/quickstart.md` for immediate execution
2. `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md` for first-PR evidence
3. `docs/README_FAST_PATHS.md` for governance and information-architecture follow-up

## 유지 규칙 / Maintenance rule

README 상단을 수정할 때는 "첫 화면 → 다음 문서 1개" handoff가 남아 있는지 먼저 확인합니다.
Keep the handoff from the first screen to one obvious next doc visible after every landing-page edit.
