# README 프로젝트 랜딩 청사진 / README project landing blueprint

## 한국어 기준 / Korean-first blueprint

README 첫 화면은 **프로젝트 소개 → 대상 사용자 → 제공 가치 → 대표 예시/카테고리 → 빠른 시작** 순서를 먼저 보여줍니다.

- 첫 화면에서 답해야 하는 질문
  1. 이 저장소는 무엇을 하는가?
  2. 누구에게 특히 맞는가?
  3. 지금 바로 무엇을 실행할 수 있는가?
- 뒤로 보내야 하는 내용
  - 운영 규칙 상세
  - 기여 세부 체크리스트 전체
  - 긴 정책/큐레이션 설명
- 첫 화면 검증 루프
  - `python3 templates/scripts/validate_template.py`
  - `docs/README_FIRST_SCREEN_CHECKLIST.md`
  - `docs/README_FIRST_SCREEN_WIREFRAME.md`

## English mirror

The first README screen should lead with **project intro -> audience -> value -> featured examples/categories -> quick start**.

- Questions the landing block must answer
  1. What does this repo do?
  2. Who is it especially for?
  3. What can I run right now?
- What should move lower
  - detailed governance rules
  - the full contribution checklist
  - long curation/policy explanations
- Validation loop
  - `python3 templates/scripts/validate_template.py`
  - `docs/README_FIRST_SCREEN_CHECKLIST.md`
  - `docs/README_FIRST_SCREEN_WIREFRAME.md`
