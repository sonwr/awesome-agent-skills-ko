# README 첫 행동 상태 메모 / README first-action status note

README 상단의 소개형 랜딩을 수정할 때, 방문자가 **첫 행동**을 바로 찾는지 빠르게 점검하기 위한 메모입니다.
A compact note for checking whether visitors can still find the **first action** immediately after README landing edits.

## 한국어 기준 / Korean-first note

- 첫 화면 안에 `python3 templates/scripts/validate_template.py`가 남아 있는가?
- 첫 검증 직후 열 문서(`examples/quickstart.md`)가 같은 흐름 안에 보이는가?
- 기여형 방문자가 `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md`로 자연스럽게 이어지는가?
- 운영 문서는 첫 화면 아래 handoff로 남아 있는가?

## English mirror

- Does `python3 templates/scripts/validate_template.py` still appear on the first screen?
- Is `examples/quickstart.md` still visible as the next doc right after the first validation step?
- Can contributor-path visitors still flow naturally into `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md`?
- Do governance docs still stay below the landing block as a handoff?

## 유지 규칙 / Maintenance rule

README 상단을 줄이거나 재배열하더라도 **소개 → 대상 사용자 → 가치 → 첫 행동** 순서는 깨지지 않아야 합니다.
Even if the README top section is compressed or reordered, the **intro -> audience -> value -> first action** sequence should stay intact.
