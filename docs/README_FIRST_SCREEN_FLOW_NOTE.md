# README first-screen flow note

README 첫 화면은 아래 순서를 잃지 않도록 유지합니다.

1. **프로젝트 소개 / Project intro** — 이 저장소가 무엇을 하는지 한눈에 설명
2. **대상 사용자 / Who it helps** — 누가 먼저 보면 좋은지 바로 명시
3. **제공 가치 / Immediate value** — 첫 화면만 읽어도 얻는 실질 가치 제시
4. **빠른 시작 / Quick start** — 첫 검증 명령과 다음 문서 연결
5. **운영 문서 이관 / Governance handoff** — 기여 규칙과 운영 문서는 하단 문서로 넘김

## 빠른 점검 질문 / Quick audit questions
- 첫 화면에서 프로젝트 의미가 먼저 보이는가?
- 첫 명령과 다음 문서가 스크롤 많이 내리지 않고 보이는가?
- 운영 규칙이 소개 블록을 밀어내고 있지 않은가?

English mirror:
Keep the first README screen in this order: project intro -> audience -> immediate value -> quick start -> governance handoff.
