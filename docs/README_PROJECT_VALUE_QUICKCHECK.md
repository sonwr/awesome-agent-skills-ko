# README 프로젝트 가치 퀵체크 / README project value quick-check

English mirror: A one-page landing check to keep the README focused on project intro, audience, value, featured examples, and quick start before governance.

## 무엇을 30초 안에 보여줘야 하나요? / What must the first 30 seconds show?

- **프로젝트 소개 / Project intro** — 한국어 기반 빌더를 위한 에이전트 스킬 큐레이션 + 실행 가능한 템플릿 모음
- **대상 사용자 / Who it helps** — 탐색·검증·기여를 한국어 기본 흐름으로 빠르게 시작하려는 개인/팀
- **제공 가치 / Immediate value** — 첫 검증 명령, 다음 문서, 첫 PR 증빙 경로를 한 화면에서 찾게 함
- **대표 예시 / Featured examples** — `examples/quickstart.md`, `examples/pr-evidence-mini-walkthrough.md`, `docs/README_FIRST_SCREEN_CHECKLIST.md`
- **빠른 시작 / Quick start** — `python3 templates/scripts/validate_template.py` → `examples/quickstart.md`

## 운영 문서는 어디에 두나요? / Where should governance live?

- README 첫 화면 아래로 내립니다.
- 기본 이동 경로: `CONTRIBUTING.md` → `docs/README_FAST_PATHS.md` → `docs/CURATION_POLICY.md`

English mirror:
- Push governance below the first screen.
- Default handoff path: `CONTRIBUTING.md` -> `docs/README_FAST_PATHS.md` -> `docs/CURATION_POLICY.md`

## 빠른 점검 질문 / Quick review questions

1. 첫 40줄 안에 프로젝트 소개와 운영 문서 handoff가 보이는가?
2. 첫 120줄 안에 대상 사용자, 가치, 대표 예시, 빠른 시작이 보이는가?
3. 첫 검증 명령과 다음 문서가 같은 화면에 있는가?
4. 운영/기여 상세 규칙이 소개 블록 위로 올라오지 않았는가?

English mirror:
1. Do the first 40 lines show the project intro plus the governance handoff?
2. Do the first 120 lines show audience, value, featured examples, and quick start?
