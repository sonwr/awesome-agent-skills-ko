# README_FIRST_SCREEN_REASSURANCE

README 첫 화면은 '링크가 너무 많아 보일까?'라는 불안을 줄여야 합니다.
English mirror: The first screen should reduce the fear that the repo is only a crowded link list.

## 체크 질문 / Audit questions

1. 이 저장소가 무엇을 하는지 첫 3줄 안에 보이는가?
2. 누가 시작하면 좋은지 첫 화면에서 바로 알 수 있는가?
3. 지금 실행할 첫 명령이 보이는가?
4. 운영 규칙이 프로젝트 소개보다 먼저 튀어나오지 않는가?
5. 대표 예시가 실제 실행/검증 문서로 연결되는가?

## 통과 기준 / Pass condition

첫 방문자가 README 첫 화면만 보고도 "무엇을 하는 저장소인지", "내가 지금 뭘 하면 되는지"를 말할 수 있으면 통과입니다.
English mirror: Pass when a first-time visitor can explain both the repo purpose and the immediate next action after reading only the first screen.
