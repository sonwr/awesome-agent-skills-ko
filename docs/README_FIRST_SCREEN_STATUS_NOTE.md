# README 첫 화면 상태 메모 / README first-screen status note

README 첫 화면은 저장소의 현재 상태를 길게 설명하기보다, **무엇을 하는 프로젝트인지 / 누가 시작하면 좋은지 / 지금 무엇을 하면 되는지**를 한 줄씩 빠르게 보여주는 방향을 유지합니다.

English mirror: The first screen should keep the repo status compact and action-oriented: what this project is, who should start here, and what to do now.

## 한 줄 상태 문장 예시 / One-line status examples

- `이 저장소는 한국어 기본 에이전트 스킬 큐레이션과 실행 템플릿을 바로 시작하게 돕습니다.`
- `첫 화면에서 소개·대상 사용자·빠른 시작을 먼저 보여주고 운영 문서는 아래로 내립니다.`

English mirror:

- `This repo helps Korean-speaking builders start from curated agent skills and runnable templates immediately.`
- `The first screen shows the project intro, audience, and quick start before governance details.`
