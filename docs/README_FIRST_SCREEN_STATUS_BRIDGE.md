# README 첫 화면 상태 브리지 / README First-screen Status Bridge

README 상단에서 소개 → 대상 사용자 → 제공 가치 → 빠른 시작으로 넘어갈 때,
중간 설명이 길어져 첫 화면 리듬이 무너지지 않았는지 짧게 점검하는 브리지 카드입니다.

## 언제 쓰나 / When to use it

- README 상단에 새 링크나 설명 문장을 추가했을 때
- 프로젝트 소개와 운영 문서 안내 사이 전환이 어색할 때
- validator는 통과하지만 첫 화면 가독성이 흐려졌다고 느껴질 때

## 30초 점검 / 30-second check

1. 프로젝트 소개 한 줄이 먼저 보이는가?
2. 대상 사용자 설명이 운영 규칙보다 먼저 나오는가?
3. 제공 가치가 단순 링크 목록처럼 보이지 않는가?
4. 빠른 시작 명령과 다음 문서가 첫 화면에서 바로 보이는가?

## 출력 원칙 / Output rule

- 한국어 기본, 필요하면 한 줄 영어 미러를 덧붙입니다.
- 운영 규칙이 필요해도 첫 화면에서는 요약만 두고 상세는 하단 문서로 내립니다.
- 첫 화면 상태 메모는 길게 쓰지 말고 다음 행동을 바로 보여줍니다.
