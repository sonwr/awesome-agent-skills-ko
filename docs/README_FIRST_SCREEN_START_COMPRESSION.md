# README 첫 화면 시작 압축 규칙 / First-screen start compression rule

첫 화면을 줄일 때는 소개 문장을 먼저 유지하고, 운영 문장보다 시작 경로를 먼저 남깁니다.

- 첫 문단에는 누가 바로 시작할 수 있는지 남깁니다.
- 첫 명령과 다음 문서는 한 묶음으로 유지합니다.
- 운영/기여 세부 문장은 첫 화면 아래 문서로 넘깁니다.

English mirror:
Keep the first-screen intro compressed around who can start now, the first command, and the next doc before lower-priority governance details.
