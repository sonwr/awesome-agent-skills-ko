# README 프로젝트 시작 맵 / README project start map

README 첫 화면을 **프로젝트 소개 → 대상 사용자 → 제공 가치 → 대표 예시/카테고리 → 빠른 시작 → 운영 handoff** 순서로 유지하기 위한 가장 짧은 시작 지도입니다.
English mirror: The shortest reusable map for keeping the README first screen ordered as **project intro -> audience -> value -> featured examples/categories -> quick start -> governance handoff**.

## 한국어 기준 / Korean-first map

1. **프로젝트 소개 / Project intro** — 이 저장소가 무엇을 하는지 한 문장으로 먼저 설명합니다.
2. **대상 사용자 / Audience** — 누가 이 저장소에서 바로 가치를 얻는지 적습니다.
3. **제공 가치 / Value** — 첫 화면만 읽어도 무엇을 실행하고 어디로 이어질지 보여줍니다.
4. **대표 예시/카테고리 / Featured examples and categories** — `examples/quickstart.md`, `examples/pr-evidence-mini-walkthrough.md`, `docs/README_FIRST_SCREEN_CHECKLIST.md`, `docs/README_FEATURED_CATEGORY_MAP.md`
5. **빠른 시작 / Quick start** — `python3 templates/scripts/validate_template.py` 실행 후 `examples/quickstart.md`로 이동합니다.
6. **운영 handoff / Governance handoff** — `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md`, `CONTRIBUTING.md`, `docs/README_FAST_PATHS.md`, `docs/CURATION_POLICY.md`는 위 흐름 아래로 보냅니다.

## English mirror

1. **Project intro** — explain what the repo does in one sentence first.
2. **Audience** — show who gets immediate value from the repo.
3. **Value** — make the first action and next document obvious from the landing block.
4. **Featured examples and categories** — keep the starter examples and IA docs visible near the top.
5. **Quick start** — run `python3 templates/scripts/validate_template.py`, then open `examples/quickstart.md`.
6. **Governance handoff** — move `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md`, `CONTRIBUTING.md`, `docs/README_FAST_PATHS.md`, and `docs/CURATION_POLICY.md` below the landing-value block.

## 유지 규칙 / Maintenance rule

- README 상단을 수정할 때는 이 문서를 기준으로 첫 화면 흐름이 끊기지 않는지 확인합니다.
- English mirror: Use this file as the source-of-truth when you need to verify that README edits still preserve the intro-first landing flow.
