# README 첫 화면 스크립트 / README first-screen script

README 상단은 소개형 랜딩처럼 읽혀야 합니다.
기여 규칙보다 먼저, 방문자가 **이 프로젝트가 무엇인지 / 누구를 위한지 / 왜 써야 하는지 / 지금 무엇을 실행할지**를 알아야 합니다.

English mirror: The README top should read like an intro-first landing page. Before contribution rules, a visitor should understand what the project is, who it is for, why it matters, and what to run now.

## 첫 화면 60초 스크립트 / 60-second first-screen script

1. **프로젝트 소개 / Project overview** — 이 저장소가 무엇인지 한 문장으로 설명합니다.
2. **대상 사용자 / Audience** — 누가 이 저장소를 가장 잘 활용하는지 밝힙니다.
3. **제공 가치 / Value** — 링크 모음이 아니라 어떤 실행 가치를 주는지 말합니다.
4. **대표 예시/카테고리 / Featured examples and categories** — 실제로 어디를 눌러야 하는지 보여줍니다.
5. **빠른 시작 / Quick start** — 첫 검증 명령과 다음 읽을 문서를 바로 제시합니다.

## README 상단에서 바로 보여줄 문장 유형 / Sentence types to keep near the top

- 한 줄 설명 / one-line summary
- 대상 사용자 / who this is for
- 실행 가치 / why it helps in practice
- 첫 명령 / first command
- 다음 문서 / next doc

## 뒤로 내려도 되는 내용 / What can move lower

- 상세 운영 규칙
- 장기 로드맵
- 기여 세부 체크리스트
- 저장소 구조 전체 설명

English mirror:
- detailed governance rules
- long-term roadmap
- contribution detail checklists
- full repository structure tour
