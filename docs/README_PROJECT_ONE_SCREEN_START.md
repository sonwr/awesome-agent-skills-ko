# README 프로젝트 원스크린 스타트 / README project one-screen start

README 첫 화면에서 프로젝트 소개, 대상 사용자, 제공 가치, 대표 예시, 빠른 시작을 한 화면 안에서 설명하기 위한 압축 기준 문서입니다.

## 한국어 기준 / Korean-first rule

- **프로젝트 소개 / Project intro** — 한국어 기반 빌더를 위한 에이전트 스킬 큐레이션 + 실행 가능한 템플릿 모음
- **대상 사용자 / Audience** — 탐색·검증·기여를 한국어 기본 흐름으로 빠르게 시작하려는 개인/팀
- **제공 가치 / Immediate value** — 첫 검증 명령, 다음 문서, 첫 PR 증빙 경로를 같은 화면에서 찾게 함
- **대표 예시 / Featured examples** — `examples/quickstart.md`, `examples/pr-evidence-mini-walkthrough.md`, `docs/README_FIRST_SCREEN_CHECKLIST.md`
- **빠른 시작 / Quick start** — `python3 templates/scripts/validate_template.py` → `examples/quickstart.md`

## English mirror

- **Project intro** — a Korean-first curation repo for agent skills and runnable templates.
- **Audience** — individuals and teams who want a fast Korean-first path for discovery, validation, and contribution.
- **Immediate value** — keep the first command, next doc, and first PR evidence path on one screen.
- **Featured examples** — `examples/quickstart.md`, `examples/pr-evidence-mini-walkthrough.md`, `docs/README_FIRST_SCREEN_CHECKLIST.md`
- **Quick start** — `python3 templates/scripts/validate_template.py` → `examples/quickstart.md`

## 유지 규칙 / Maintenance rule

README 상단을 수정할 때는 이 문서와 `docs/README_PROJECT_HOME_PANEL.md`, `docs/README_PROJECT_START_HERE.md`를 함께 검토해 소개 우선 구조가 유지되는지 확인합니다.
