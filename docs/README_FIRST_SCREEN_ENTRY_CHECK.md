# README 첫 화면 진입 점검 / README first-screen entry check

README 상단을 수정할 때, 첫 화면이 여전히 프로젝트 소개 중심으로 읽히는지 빠르게 확인하기 위한 점검 카드입니다.

## 30초 점검 / 30-second check

1. **프로젝트 소개가 먼저 보이는가? / Does the project intro appear first?**
   - 한국어 기본 프로젝트 설명과 영어 미러가 첫 화면 초반에 남아 있어야 합니다.
2. **대상 사용자와 즉시 가치가 붙어 있는가? / Are audience and immediate value still adjacent?**
   - 소개 뒤에 대상 사용자·제공 가치가 바로 이어져야 intro-first 흐름이 유지됩니다.
3. **대표 경로가 바로 보이는가? / Are the featured paths immediately visible?**
   - 대표 카테고리, 대표 예시, 빠른 시작 명령이 첫 화면에서 찾혀야 합니다.
4. **운영 문서가 위로 치고 올라오지 않았는가? / Did governance docs stay lower?**
   - 운영 규칙은 필요하지만, 첫 화면에서는 프로젝트 가치보다 앞서면 안 됩니다.

## 유지 기준 / Maintenance rule

README 첫 화면은 링크를 많이 늘리는 곳이 아니라, **프로젝트를 이해하고 첫 행동을 고르는 화면**이어야 합니다.
