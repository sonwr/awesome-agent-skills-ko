# README 프로젝트 가치 사다리 / README project value ladder

README 상단이 무엇을 먼저 약속해야 하는지 한 줄씩 정리한 문서입니다.
English mirror: A compact ladder showing what the README top should promise first, line by line.

## 한국어 기준 / Korean-first ladder

1. **프로젝트 소개** — 이 저장소가 무엇을 하는지 먼저 말합니다.
2. **대상 사용자** — 누가 이 저장소로 바로 도움을 받는지 보여줍니다.
3. **즉시 얻는 가치** — 첫 화면만 읽고 무엇을 바로 할 수 있는지 말합니다.
4. **대표 예시/카테고리** — 탐색·검증·기여 경로를 예시로 보여줍니다.
5. **빠른 시작** — 첫 명령과 다음 문서를 같은 화면에서 연결합니다.
6. **운영 문서 handoff** — CONTRIBUTING/운영 규칙은 아래로 내려 보냅니다.

## English mirror

1. **Project intro** — say what the repo does first.
2. **Audience** — show who gets value immediately.
3. **Immediate value** — explain what a visitor can do right away.
4. **Featured examples/categories** — expose discovery, validation, and contribution routes.
5. **Quick start** — keep the first command and next document on the same screen.
6. **Governance handoff** — move CONTRIBUTING/operations docs lower.

## 유지 규칙 / Maintenance rule

README 상단을 수정할 때는 이 순서를 깨지 않았는지 먼저 확인하고, 이후 `python3 templates/scripts/validate_template.py`를 실행합니다.
English mirror: When editing the README top, confirm this order first, then run `python3 templates/scripts/validate_template.py`.
