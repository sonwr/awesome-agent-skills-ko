# 기여/운영 확장 가이드 / Contributor and operations guide

README 상단은 소개형 랜딩에 집중하고, 반복되는 운영/기여 상세 흐름은 이 문서에서 관리합니다.

## 이 문서가 다루는 것 / What lives here

- 역할별 상세 운영 문서 이동 경로
- 첫 PR 증빙 준비 흐름
- README 상단 이후에 읽으면 좋은 운영 문서 묶음
- 반복 작업 방지용 점검 포인트

## 권장 읽기 순서 / Recommended reading order

1. `README.md` 상단의 프로젝트 소개/대상 사용자/제공 가치/빠른 시작 확인
2. `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md`로 최소 증빙 규칙 확인
3. `examples/pr-evidence-mini-walkthrough.md`로 PR 코멘트 형식 복붙
4. 운영 감사를 하려면 `docs/README_FAST_PATHS.md`, `docs/README_INFORMATION_ARCHITECTURE.md`, `docs/CURATION_POLICY.md` 순서로 이동

## 운영 메모 / Operations note

README에는 방문자에게 필요한 첫 이동만 남기고, 중복되는 운영형 상세 카드와 확장 설명은 여기서 유지합니다.
