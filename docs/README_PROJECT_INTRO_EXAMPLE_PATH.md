# README 프로젝트 인트로 예시 경로 / README project intro example path

README 상단의 프로젝트 소개 블록은 방문자가 **무엇을 얻는지 → 어디서 시작하는지 → 어떤 예시를 먼저 보는지** 순서로 안내해야 한다.

The opening project-intro block should guide a first-time visitor in this order: **what they get → where to start → which example to open first**.

## 권장 흐름 / Recommended flow

1. 프로젝트 한 줄 소개 / One-line project value statement
2. 대표 사용 사례 1~2개 / 1-2 featured use cases
3. 첫 행동 링크 / First action link
4. 가장 짧은 예시 링크 / Shortest example link
5. 유지보수/기여 링크 / Maintenance or contribution link

## 짧은 예시 문장 / Short sample copy

- 이 저장소는 에이전트 스킬을 빠르게 찾고 바로 적용할 수 있게 정리한다.
- 처음 왔다면 `빠른 시작`과 `대표 예시`부터 확인한다.
- 기여 전에는 `기여 체크리스트`를 읽고 형식을 맞춘다.

- This repository helps visitors find agent skills fast and apply them immediately.
- If this is your first visit, start with `Quick Start` and `Featured Examples`.
- Before contributing, read the contribution checklist and match the format.
