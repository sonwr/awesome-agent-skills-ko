# 프로젝트 방향 / Project direction

## 장기 방향 (한국어)

이 저장소는 일회성 링크 목록이 아니라, 오래 유지되는 공개 자원을 목표로 합니다.

### 1) 양보다 큐레이션
- 적더라도 더 좋은 항목을 우선합니다.
- 각 항목은 실무성, 재현성, 유지보수성을 보여줘야 합니다.

### 2) 런타임 휴대성
- 특정 벤더 런타임 고정 구조를 피합니다.
- 무엇이 종속적이고 무엇이 이식 가능한지 문서화합니다.

### 3) 증빙 기반 품질
- setup, expected output, validation, limitation을 함께 남깁니다.
- “대충 좋아 보인다” 식 승인 흐름을 피합니다.

### 4) 기여자 친화적 운영
- 신규 기여자가 빠르게 읽고 재현하고 리뷰받을 수 있어야 합니다.
- 온보딩 문서, 예시, 체크리스트를 안정적으로 유지합니다.

### 5) 지속 가능한 릴리스 리듬
- 작은 단위의 자주 있는 업데이트를 선호합니다.
- 주기적인 정리와 추천 세트 스냅샷을 유지합니다.

## Long-term direction (English)

This repository is meant to be a durable public resource, not a one-off list.

### 1) Curation over volume
- Prefer fewer, better entries.
- Each addition should prove practical use, reproducibility, and maintainability.

### 2) Runtime portability
- Avoid locking the collection to one vendor runtime.
- Document what is runtime-specific versus portable.

### 3) Evidence-driven quality
- Require setup, expected output, validation, and limitations together.
- Avoid “looks good” approval culture.

### 4) Contributor-friendly governance
- Keep onboarding, examples, and checklists stable for newcomers.
- Make review expectations explicit and repeatable.

### 5) Sustainable release rhythm
- Prefer small frequent updates over chaotic bursts.
- Maintain periodic cleanups and recommended snapshot sets.
