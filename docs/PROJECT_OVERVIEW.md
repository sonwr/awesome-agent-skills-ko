# 프로젝트 개요 / Project overview

## 왜 이 프로젝트가 필요한가 (한국어)

많은 스킬 저장소는 다음 둘 중 하나에 치우칩니다.

- 바로 실행하기에는 너무 추상적이거나
- 특정 런타임/도구체인에 너무 강하게 묶여 있습니다.

`awesome-agent-skills-ko`는 그 중간 지점을 목표로 합니다.

1. **이해하기 쉬운 큐레이션 구조**
2. **최소 설정으로 실행 가능한 템플릿**
3. **리뷰/검증/운영 기준이 함께 있는 장기 유지보수 흐름**

## Why this project exists (English)

Many skill repositories lean too far toward one of two extremes:

- too abstract to run immediately, or
- too tightly coupled to a single runtime or toolchain.

`awesome-agent-skills-ko` targets the practical middle:

1. **curated structures** that are easy to understand,
2. **runnable templates** with minimal setup,
3. **long-term maintenance rails** backed by review, validation, and governance docs.
