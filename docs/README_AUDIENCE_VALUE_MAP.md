# README 대상 사용자-가치 맵 / README audience-value map

README 상단을 프로젝트 소개 우선 구조로 유지할 때, 어떤 독자에게 어떤 가치를 먼저 보여줄지 정리한 문서입니다.
English mirror: A quick reference for who the intro-first README is for and which value cue should appear first for each audience.

## 한국어 기준 / Korean-first map

- **탐색형 방문자** — 프로젝트 소개, 대표 카테고리, examples/quickstart.md를 먼저 보여줍니다.
- **기여형 방문자** — 첫 검증 명령, docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md, examples/pr-evidence-mini-walkthrough.md를 먼저 묶습니다.
- **운영형 방문자** — docs/README_FAST_PATHS.md, docs/README_FIRST_SCREEN_CHECKLIST.md, docs/CURATION_POLICY.md로 이어지는 감사 경로를 명확히 둡니다.
- **한 줄 원칙** — README 상단은 소개 -> 대상 사용자 -> 제공 가치 -> 대표 예시/빠른 시작 순서를 먼저 지키고, 운영 규칙은 아래로 내립니다.

## English mirror

- **Explorer visitors** — show the project intro, featured categories, and `examples/quickstart.md` first.
- **Contributors** — bundle the first validation command, `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md`, and `examples/pr-evidence-mini-walkthrough.md` together.
- **Operators** — keep the audit path explicit: `docs/README_FAST_PATHS.md` -> `docs/README_FIRST_SCREEN_CHECKLIST.md` -> `docs/CURATION_POLICY.md`.
- **One-line rule** — keep the README top focused on intro -> audience -> value -> examples/quick start, and move governance details lower.
