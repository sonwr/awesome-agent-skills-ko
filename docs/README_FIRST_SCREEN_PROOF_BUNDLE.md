# README 첫 화면 증빙 번들 / README first-screen proof bundle

README 첫 화면을 intro-first로 유지할 때, 소개 문장만 고치는 것으로 끝내지 말고 **증빙 묶음**까지 같이 확인합니다.

## 한국어 기준 / Korean-first bundle

첫 화면에서 최소한 아래 네 가지가 같이 보여야 합니다.

1. **프로젝트 소개 / Project intro** — 이 저장소가 무엇을 하는지 한 줄로 설명한다.
2. **대상 사용자 / Who it helps** — 누가 먼저 읽으면 좋은지 바로 말한다.
3. **첫 실행 / First action** — `python3 templates/scripts/validate_template.py` 같은 복사 가능한 첫 명령을 둔다.
4. **다음 문서 / Next doc** — `examples/quickstart.md` 같은 바로 이어지는 문서를 붙인다.

## English mirror

When keeping the README intro-first, do not stop at the project pitch.
Keep the proof bundle visible too:

1. project intro,
2. audience fit,
3. copyable first command,
4. next document to open.

## 유지 규칙 / Maintenance rule

README 상단을 고친 뒤에는 첫 화면만 보고도
`프로젝트 소개 → 대상 사용자 → 첫 실행 → 다음 문서`
순서가 이어지는지 다시 확인합니다.
