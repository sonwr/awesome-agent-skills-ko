# 첫 클릭 가이드 / First-click guide

README 첫 화면에서 바로 고를 수 있는 첫 행동 기준입니다.

English mirror: This guide helps first-time visitors choose the right first click directly from the README landing area.

## 언제 이 문서를 보나요? / When to use this

- **탐색형 / Explore-first** — 프로젝트 소개와 대표 가치를 먼저 이해하고 싶을 때
- **실행형 / Validate-now** — 바로 검증 명령과 다음 문서로 넘어가고 싶을 때
- **기여형 / Contribute-now** — 첫 PR 증빙 형식과 체크리스트를 바로 열고 싶을 때
- **운영형 / Audit-first** — README 정보구조와 운영 기준을 점검하고 싶을 때

English mirror:
- **Explore-first** — understand the project intro and value first.
- **Validate-now** — jump straight to the validation command and next doc.
- **Contribute-now** — open the first PR evidence format and checklist immediately.
- **Audit-first** — review the README information architecture and governance paths.

## 첫 클릭 매핑 / First-click mapping

- **탐색형 / Explore-first** → `프로젝트 소개 / Project overview`
- **실행형 / Validate-now** → `python3 templates/scripts/validate_template.py` → `examples/quickstart.md`
- **기여형 / Contribute-now** → `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md` → `examples/pr-evidence-mini-walkthrough.md`
- **운영형 / Audit-first** → `docs/README_FIRST_SCREEN_CHECKLIST.md` → `docs/README_FAST_PATHS.md`

## 유지 규칙 / Maintenance rule

README 상단의 소개 → 대상 사용자 → 제공 가치 → 대표 예시/카테고리 → 빠른 시작 흐름을 깨지 않는 범위에서만 첫 클릭 링크를 추가합니다.

English mirror: Only add first-click links if they preserve the landing order of intro -> audience -> value -> featured examples/categories -> quick start.
