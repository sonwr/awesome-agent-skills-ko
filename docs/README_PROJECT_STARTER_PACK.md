# README 프로젝트 스타터 팩 / README project starter pack

README 상단을 처음 여는 방문자가 **프로젝트 소개 → 대상 사용자 → 제공 가치 → 대표 예시/카테고리 → 빠른 시작**을 한 번에 이해하도록 돕는 요약 팩입니다.

## 한국어 기준 / Korean-first pack

### 1) 프로젝트 소개 한 줄
- 이 저장소는 한국어 기반 빌더가 검증 가능한 에이전트 스킬과 실행 템플릿을 빠르게 찾도록 돕는 큐레이션 저장소입니다.

### 2) 대상 사용자 한 줄
- 탐색형, 기여형, 운영형 방문자가 각자 첫 클릭 문서를 바로 고를 수 있어야 합니다.

### 3) 제공 가치 한 줄
- 첫 화면에서 첫 검증 명령, 다음 문서, 첫 PR 증빙 경로를 함께 보여줘 실행 비용을 낮춥니다.

### 4) 대표 예시/카테고리 한 줄
- `examples/quickstart.md`, `examples/pr-evidence-mini-walkthrough.md`, `docs/README_FIRST_SCREEN_CHECKLIST.md`, `docs/README_FEATURED_CATEGORY_MAP.md`

### 5) 빠른 시작 한 줄
- `python3 templates/scripts/validate_template.py` 실행 → `examples/quickstart.md` 열기

## English mirror

### 1) Project intro
- This repo curates validation-ready agent skills and runnable templates for Korean-speaking builders.

### 2) Audience
- Explorer, contributor, and operator visitors should each find their first-click document immediately.

### 3) Value
- The first screen keeps the validation command, next doc, and first-PR evidence path visible together.

### 4) Featured examples/categories
- `examples/quickstart.md`, `examples/pr-evidence-mini-walkthrough.md`, `docs/README_FIRST_SCREEN_CHECKLIST.md`, `docs/README_FEATURED_CATEGORY_MAP.md`

### 5) Quick start
- Run `python3 templates/scripts/validate_template.py` and then open `examples/quickstart.md`.

## 유지 규칙 / Maintenance rule

- README 상단을 고친 뒤에는 `python3 templates/scripts/validate_template.py`를 실행합니다.
- 기여 규칙, 체크리스트, 운영 문서는 첫 화면 아래에 두고 이 문서는 소개형 상단 요약을 유지하는 데 사용합니다.
