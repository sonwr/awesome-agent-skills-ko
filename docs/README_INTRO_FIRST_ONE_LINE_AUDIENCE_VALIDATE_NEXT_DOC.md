# README intro-first one-line audience -> validate -> next-doc

소개 바로 아래에서는 **대상 사용자 -> 첫 검증 명령 -> 다음 문서**가 한 줄 handoff처럼 읽혀야 합니다.

- 소개를 줄이더라도 이 세 요소의 순서는 깨지지 않게 유지합니다.
- validator 통과 전에는 README 상단 변경을 커밋/푸시하지 않습니다.
- 가능하면 `examples/quickstart.md` 또는 `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md` 중 다음 문서를 바로 이어서 보여줍니다.

English mirror:

Keep **audience -> first validation command -> next doc** readable like one handoff directly under the intro.

- Preserve that order even when compressing the opening copy.
- Do not commit or push README-top edits before the validator passes.
- Prefer showing `examples/quickstart.md` or `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md` immediately as the next-doc handoff.
