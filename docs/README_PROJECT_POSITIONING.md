# README 프로젝트 포지셔닝 / README project positioning

README 첫 화면이 무엇을 먼저 말해야 하는지, 그리고 어떤 독자를 위해 어떤 가치를 앞세워야 하는지 정리한 문서입니다.
This document explains what the first README screen should say first, which audience it serves, and which value signals should appear before governance details.

## 포지셔닝 문장 / Positioning statement

- 한국어 기본 빌더가 바로 실행 가능한 스킬/템플릿을 찾고 검증 경로까지 이어지게 만드는 큐레이션 저장소입니다.
- README 첫 화면은 링크 나열보다 프로젝트 소개, 대상 사용자, 제공 가치, 대표 시작 예시, 빠른 시작을 우선합니다.

English mirror:
- A Korean-first curation repo that helps builders find runnable skills/templates and continue directly into validation paths.
- The first README screen should prioritize project intro, audience, value, featured starter examples, and quick start before link-heavy governance details.

## 첫 화면에서 먼저 약속할 가치 / Value promises to show first

- **무엇을 하는가 / What it does** — 스킬 큐레이션 + 실행 가능한 템플릿 + 검증 진입점
- **누구를 돕는가 / Who it helps** — 한국어 기본 흐름으로 탐색·검증·기여하려는 빌더/팀
- **지금 바로 되는 일 / Immediate action** — `python3 templates/scripts/validate_template.py`와 `examples/quickstart.md`
- **운영 문서 이동 경로 / Governance handoff** — `docs/README_FAST_PATHS.md`, `CONTRIBUTING.md`, `docs/CURATION_POLICY.md`

English mirror:
- **What it does** — skill curation + runnable templates + validation entry points
- **Who it helps** — builders and teams who want Korean-first discovery, validation, and contribution flows
- **Immediate action** — `python3 templates/scripts/validate_template.py` and `examples/quickstart.md`
- **Governance handoff** — `docs/README_FAST_PATHS.md`, `CONTRIBUTING.md`, and `docs/CURATION_POLICY.md`

## 먼저 보이고 뒤로 내릴 것 / What stays first vs lower

- 먼저 보일 것: 프로젝트 소개, 대상 사용자, 제공 가치, 대표 시작 예시, 빠른 시작
- 뒤로 내릴 것: 전체 기여 규칙, 세부 운영 체크리스트, 장기 정책 설명

English mirror:
- Keep first: project overview, audience, value, featured starter examples, and quick start.
- Move lower: full contribution rules, detailed operations checklists, and long-form governance policy.
