# README_FIRST_SCREEN_ONE_MINUTE_CHECK

README 첫 화면을 1분 안에 훑으면서 intro-first 구조가 유지되는지 확인하는 짧은 점검 카드입니다.

English mirror: A short one-minute audit card for checking whether the README still preserves the intro-first landing flow.

## 1분 점검 / One-minute audit

1. **프로젝트 소개가 먼저 보이는가? / Is the project intro visible first?**
2. **대상 사용자와 제공 가치가 첫 화면에 남아 있는가? / Do audience and value stay on the first screen?**
3. **첫 행동(검증 명령/대표 예시/다음 문서)이 바로 보이는가? / Is the first action visible immediately?**
4. **운영 문서가 상단을 잠식하지 않는가? / Do governance docs stay below the landing block?**

## 합격 신호 / Pass signal

상단 소개만 읽어도 저장소 목적, 대상 사용자, 첫 검증 명령, 다음 문서가 1분 안에 파악되면 합격입니다.

English mirror: Pass when the repo purpose, target audience, first validation command, and next doc are understandable within one minute from the README top.
