# README 역할별 시작 퀵 가이드 / README role start quick guide

README 첫 화면을 읽은 뒤 바로 다음 문서를 고를 때 쓰는 60초 압축 가이드입니다.
English mirror: A 60-second guide for choosing the next doc right after reading the first README screen.

## 탐색형 / Explorer

- 먼저 볼 것: `프로젝트 소개 / Project overview`
- 다음 문서: `examples/quickstart.md`
- 얻는 것: 저장소 가치와 대표 예시를 가장 빠르게 파악

## 기여형 / Contributor

- 먼저 할 것: `python3 templates/scripts/validate_template.py`
- 다음 문서: `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md`
- 얻는 것: 첫 PR에 필요한 최소 증빙과 병기 규칙

## 운영형 / Operator

- 먼저 볼 것: `docs/README_FIRST_SCREEN_CHECKLIST.md`
- 다음 문서: `docs/README_FAST_PATHS.md`
- 얻는 것: intro-first 랜딩 구조와 운영 기준 점검 경로

## 한 줄 규칙 / One-line rule

README 상단에서는 소개 → 대상 사용자 → 가치 → 빠른 시작을 먼저 보고, 운영 문서는 역할별 다음 문서로 넘깁니다.
English mirror: Keep the top README scan focused on intro -> audience -> value -> quick start, then branch into role-specific operating docs.
