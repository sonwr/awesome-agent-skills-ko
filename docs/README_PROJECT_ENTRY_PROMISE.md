# README 프로젝트 진입 약속 / README project entry promise

README 첫 화면이 무엇을 먼저 약속해야 하는지 압축한 문서입니다.
English mirror: A compact note describing what the README landing area should promise first.

## 첫 화면 약속 / First-screen promise

1. **이 저장소가 무엇인지 바로 설명한다.**
   - 프로젝트 소개 한 줄이 먼저 보여야 합니다.
2. **누가 쓰는지 바로 연결한다.**
   - 탐색형 / 기여형 / 운영형 방문자가 자기 경로를 바로 찾을 수 있어야 합니다.
3. **무엇을 바로 할 수 있는지 보여준다.**
   - 첫 검증 명령과 다음 문서가 README 상단에서 보여야 합니다.
4. **대표 예시와 카테고리를 함께 건넨다.**
   - quickstart, PR 증빙, 랜딩 감사 문서가 첫 화면 흐름 안에 있어야 합니다.
5. **운영 문서는 아래로 보낸다.**
   - 기여 규칙, 정책, 장기 운영 문서는 소개/가치/빠른 시작 뒤로 내려갑니다.

## 추천 확인 질문 / Review questions

- README 첫 1분 안에 프로젝트 의미가 보이는가?
- 첫 검증 명령이 깊게 숨지 않았는가?
- 운영 문서가 소개보다 먼저 보이지 않는가?
- 대표 예시/카테고리/빠른 시작이 한 흐름으로 이어지는가?
