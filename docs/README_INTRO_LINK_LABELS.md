# README intro 링크 라벨 원칙 / README intro link label rules

README 상단 intro 구간의 링크 라벨은 첫 방문자가 바로 이해할 수 있어야 한다.

## 기본 원칙

- 링크 텍스트만 봐도 무엇을 얻는지 보여준다.
- 가능하면 행동 중심 동사를 쓴다.
- 내부 작성자 용어보다 사용자 용어를 우선한다.
- 비슷한 의미의 라벨을 여러 개 섞지 않는다.

## 권장 예시

- 지금 어디서 시작할지 보기
- 대표 활용 예시 보기
- 설치 없이 빠르게 훑어보기
- 유지보수 방식 이해하기

## Avoid / 피하기

- 모호한 명사만 있는 라벨
- 문서 구조를 알아야 이해되는 이름
- 같은 구간에서 한국어/영어 톤이 제각각인 링크
