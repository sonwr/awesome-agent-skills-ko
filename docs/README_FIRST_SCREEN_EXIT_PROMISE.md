# README 첫 화면 종료 약속 / README first-screen exit promise

README 첫 화면을 다 읽은 뒤 방문자가 **무엇을 하는 저장소인지 / 누구를 위한지 / 지금 무엇을 할지** 말할 수 있게 만드는 종료 기준 문서입니다.
Use this exit-promise card to confirm that the README first screen leaves visitors knowing the repo purpose, audience, and immediate next action.

## 한국어 기준 / Korean-first promise

- **프로젝트를 설명할 수 있어야 함** — 한국어 기본 큐레이션 + 실행 가능한 템플릿 저장소라는 점이 남아야 합니다.
- **대상 사용자를 말할 수 있어야 함** — 탐색·검증·기여를 빠르게 시작하려는 개인/팀을 위한 저장소임이 보여야 합니다.
- **첫 행동이 남아야 함** — `python3 templates/scripts/validate_template.py` 또는 다음 문서(`examples/quickstart.md`, `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md`) 중 하나를 바로 고를 수 있어야 합니다.
- **운영 규칙은 아래에 있다는 감각이 남아야 함** — 첫 화면은 소개와 실행 경로 중심이고, 운영 문서는 아래로 이어진다는 흐름이 보여야 합니다.

## English mirror

- **The repo purpose should be memorable** — visitors should leave the first screen knowing this is a Korean-first curation repo with runnable templates.
- **The audience should be obvious** — the landing area should still point to builders and teams who want a fast discovery/validation/contribution path.
- **The first action should remain visible** — a visitor should be able to choose the validation command or the next doc immediately.
- **Governance should feel like a lower handoff, not the opener** — the first screen should end with a route into rules, not start there.

## 유지 규칙 / Maintenance rule

README 상단을 바꾼 뒤에는 이 문서 기준으로 "소개 → 대상 사용자 → 제공 가치 → 첫 행동 → 운영 문서 핸드오프" 흐름이 여전히 첫 화면 안에 남는지 확인합니다.
After each README landing rewrite, verify that the first screen still preserves the flow: intro -> audience -> value -> first action -> governance handoff.
