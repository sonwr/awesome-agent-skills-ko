# README first-run decider

README 첫 화면에서 처음 방문자가 바로 무엇을 해야 하는지 15초 안에 고르게 만드는 보조 문서입니다.
English mirror: A helper doc for making the first README screen answer "what should I do first?" within 15 seconds.

## 빠른 선택 / Fast chooser

- **탐색 먼저 / Explore first** — 프로젝트 소개 → 프로젝트 한눈에 보기
- **바로 검증 / Validate now** — `python3 templates/scripts/validate_template.py` → `examples/quickstart.md`
- **바로 기여 / Contribute now** — `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md` → `examples/pr-evidence-mini-walkthrough.md`
- **운영 점검 / Audit now** — `docs/README_FIRST_SCREEN_CHECKLIST.md` → `docs/README_FAST_PATHS.md`

## 유지 규칙 / Maintenance rule

README 상단을 바꿀 때는 소개, 대상 사용자, 가치, 첫 행동, 다음 문서가 첫 화면에 남아 있는지 먼저 확인합니다.
English mirror: When editing the top of the README, verify that the intro, audience, value, first action, and next doc still stay on the first screen.
