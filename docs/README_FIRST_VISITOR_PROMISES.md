# README 첫 방문 약속 / README first-visitor promises

README 첫 화면에서 신규 방문자가 바로 이해해야 하는 핵심 약속을 압축한 문서입니다.
English mirror: A compressed map of the promises first-time visitors should understand from the README landing area.

## 한국어 기준 / Korean-first promises

- **무엇을 찾는 저장소인가?** 한국어 기본 흐름으로 에이전트 스킬과 실행 가능한 템플릿을 찾는 저장소입니다.
- **누가 바로 도움을 받는가?** 탐색형·기여형·운영형 빌더가 각자 다음 문서를 1클릭으로 고를 수 있습니다.
- **어떤 가치를 즉시 얻는가?** 첫 검증 명령, 대표 예시, 첫 PR 증빙 경로가 README 상단에서 바로 보입니다.
- **무엇을 먼저 실행하는가?** `python3 templates/scripts/validate_template.py` 실행 후 `examples/quickstart.md`로 이동합니다.
- **운영 문서는 어디로 가는가?** 운영/정책/장기 방향 문서는 README 상단이 아니라 `docs/README_FAST_PATHS.md`, `CONTRIBUTING.md`, `docs/CURATION_POLICY.md`로 내려 보냅니다.

## English mirror

- **What kind of repo is this?** A Korean-first collection of agent skills and runnable templates.
- **Who gets value immediately?** Explorer, contributor, and operator visitors can each choose the next document in one click.
- **What value appears right away?** The first validation command, featured examples, and first-PR evidence path are visible from the README landing area.
- **What should run first?** Run `python3 templates/scripts/validate_template.py`, then open `examples/quickstart.md`.
- **Where does governance move?** Push governance/policy/long-range docs below the landing area into `docs/README_FAST_PATHS.md`, `CONTRIBUTING.md`, and `docs/CURATION_POLICY.md`.
