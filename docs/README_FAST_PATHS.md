# README 빠른 진입 경로 / README fast paths

README 상단을 소개형 랜딩으로 유지하면서도, 첫 방문자가 60초 안에 다음 문서를 고를 수 있게 돕는 압축 가이드입니다.
English mirror: This companion guide keeps the README intro-first while giving first-time visitors a 60-second path chooser.

README의 `핵심 시작 버튼 / Core start buttons` 섹션은 이 문서의 Explorer / Contributor / Operator 흐름을 더 짧게 요약한 버전입니다. 버튼을 누른 뒤에는 `카테고리 바로가기`, `역할별 30초 선택 카드`, `역할별 1클릭 다음 문서`가 같은 순서로 후속 이동을 이어받아야 합니다.
English mirror: The README `Core start buttons` section is the compressed first-screen version of the Explorer / Contributor / Operator paths documented here. After a visitor picks a button, the README `Category jump links`, `30-second role chooser cards`, and `Role-based 1-click next docs` sections should continue the same handoff order.

## 탐색형 60초 경로 / Explorer 60-second path

- README의 프로젝트 소개 → 대상 사용자 → 제공 가치만 먼저 읽습니다.
- 이어서 `examples/quickstart.md`로 이동해 첫 명령과 다음 읽기 순서를 확인합니다.

English mirror:
- Read only the README overview, audience, and value sections first.
- Then open `examples/quickstart.md` for the first command and next reading order.

## 기여형 60초 경로 / Contributor 60-second path

- `python3 templates/scripts/validate_template.py`를 먼저 실행합니다.
- 그다음 `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md`와 `examples/pr-evidence-mini-walkthrough.md`를 엽니다.

English mirror:
- Run `python3 templates/scripts/validate_template.py` first.
- Then open `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md` and `examples/pr-evidence-mini-walkthrough.md`.

## 운영형 60초 경로 / Operator 60-second path

- `docs/README_INFORMATION_ARCHITECTURE.md`와 `docs/README_FIRST_SCREEN_CHECKLIST.md`를 먼저 읽습니다.
- 필요하면 `docs/PROJECT_ENTRY_PATHS.md`와 `docs/CURATION_POLICY.md`로 내려갑니다.

English mirror:
- Start with `docs/README_INFORMATION_ARCHITECTURE.md` and `docs/README_FIRST_SCREEN_CHECKLIST.md`.
- Continue with `docs/PROJECT_ENTRY_PATHS.md` and `docs/CURATION_POLICY.md` when you need governance detail.

## README 역할 카드와의 연결 / How this maps to README role cards

- README의 `추천 시작 경로`, `역할별 30초 선택 카드`, `역할별 바로 열 문서`는 이 문서의 Explorer / Contributor / Operator 순서를 그대로 따라야 합니다.
- README 상단 카드는 소개형 랜딩을 유지하고, 자세한 이동 경로는 이 문서에서 이어 받습니다.
- README의 `역할별 바로 점프 / Role-based instant jumps`는 이 문서의 세 역할 섹션 앵커로 직접 연결되어야 합니다.

English mirror:
- The README sections `Recommended starting paths`, `30-second role chooser cards`, and `Role-based first-open docs` should keep the same Explorer / Contributor / Operator order as this guide.
- Keep the README landing area intro-first, then hand detailed navigation off to this file.
- The README `Role-based instant jumps` block should point directly at the three role sections in this document.
