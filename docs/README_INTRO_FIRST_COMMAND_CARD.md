# README intro-first command card

README 첫 화면을 손볼 때는 소개 문장만 줄이지 말고 **첫 명령 + 다음 문서**가 함께 남아 있는지 먼저 확인합니다.

## 핵심 규칙 / Core rule
- 첫 화면 상단에 `python3 templates/scripts/validate_template.py`가 보여야 합니다.
- 같은 시야 안에 `examples/quickstart.md`가 이어져야 합니다.
- 한국어 소개 문장과 영어 미러는 이 실행 경로를 가리지 않아야 합니다.

## 빠른 점검 / Quick check
1. 이 저장소가 누구를 위한지 첫 2~3줄 안에 보이는가?
2. 첫 검증 명령이 첫 화면에서 바로 보이는가?
3. 다음 문서가 같은 첫 화면 블록에서 이어지는가?
4. 운영/기여 문서는 그 아래로 내려가 있는가?
