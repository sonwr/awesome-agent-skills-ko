# README 프로젝트 시작 신호 / Project start signal

README 상단이 intro-first 구조를 제대로 지키는지 빠르게 확인할 때 쓰는 짧은 기준입니다.

## 시작 신호 / Start signals

1. 첫 화면에서 저장소 정체성이 바로 드러난다.  
   The repository identity is obvious on the first screen.
2. 설치보다 먼저 왜 봐야 하는지가 나온다.  
   The README explains why the project matters before setup details.
3. 초보자용 첫 이동 경로가 한 번에 보인다.  
   A beginner can see the first navigation path at a glance.
4. 예시·카테고리·기여 링크가 소개를 방해하지 않는다.  
   Example, category, and contribution links do not interrupt the intro.

## 빠른 점검 질문 / Quick review questions

- 첫 30초 안에 "이 저장소가 무엇을 주는지" 이해되는가?
- 첫 번째 클릭 후보가 너무 많지 않은가?
- 소개 문단이 링크 묶음보다 먼저 신뢰를 주는가?

이 문서는 README 개편 시 상단 구조를 줄이지 않고도 intro-first 품질을 확인하는 보조 카드로 사용합니다.
