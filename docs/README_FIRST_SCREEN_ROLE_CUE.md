# README 첫 화면 역할 큐 / README first-screen role cue

## 한국어 기준 / Korean-first cue
- 탐색형 방문자는 프로젝트 소개와 빠른 시작 명령을 첫 화면에서 바로 봐야 합니다.
- 기여형 방문자는 첫 검증 명령 다음에 곧바로 기여 체크리스트로 이어져야 합니다.
- 운영형 방문자는 첫 화면 아래로 내려가기 전에 intro-first 유지 문서를 바로 찾을 수 있어야 합니다.

## English mirror
- Explorers should see the project intro and first validation command on the first screen.
- Contributors should move from the first validation command straight into the contribution checklist.
- Operators should find the intro-first maintenance docs before scrolling into deeper governance content.
