# README 첫 화면 지도 / README first-screen map

README 상단을 **프로젝트 소개 → 대상 사용자 → 제공 가치 → 대표 예시/카테고리 → 빠른 시작 → 운영 handoff** 순서로 유지하기 위한 압축 지도입니다.
English mirror: A compact map for keeping the README first screen ordered as **project intro -> audience -> value -> featured examples/categories -> quick start -> governance handoff**.

## 한국어 기준 / Korean-first map

1. **프로젝트 소개 / Project intro** — 저장소가 무엇인지 한 줄로 먼저 설명합니다.
2. **대상 사용자 / Who it helps** — 누구에게 맞는 저장소인지 바로 드러냅니다.
3. **제공 가치 / Immediate value** — 첫 검증 명령, 다음 문서, 대표 사용 장면을 보여줍니다.
4. **대표 예시/카테고리 / Featured examples/categories** — 빠르게 복사하거나 탐색할 예시를 붙입니다.
5. **빠른 시작 / Quick start** — `python3 templates/scripts/validate_template.py` → `examples/quickstart.md`
6. **운영 handoff / Governance handoff** — `CONTRIBUTING.md`, `docs/README_FAST_PATHS.md`, `docs/CURATION_POLICY.md`는 위 블록 아래로 보냅니다.

## English mirror

1. **Project intro** — explain what the repo is in one line first.
2. **Who it helps** — show the intended audience immediately.
3. **Immediate value** — surface the first validation command, next doc, and representative usage path.
4. **Featured examples/categories** — keep copyable examples and category cues nearby.
5. **Quick start** — `python3 templates/scripts/validate_template.py` -> `examples/quickstart.md`
6. **Governance handoff** — keep `CONTRIBUTING.md`, `docs/README_FAST_PATHS.md`, and `docs/CURATION_POLICY.md` below the landing-value block.

## 유지 규칙 / Maintenance rule

- README 상단 순서를 바꿨다면 이 문서와 `docs/README_FIRST_SCREEN_CHECKLIST.md`를 함께 갱신합니다.
- English mirror: If you change the README first-screen order, update this doc together with `docs/README_FIRST_SCREEN_CHECKLIST.md`.
