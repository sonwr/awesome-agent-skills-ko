# README landing status note

README 상단을 고칠 때는 소개 → 대상 사용자 → 제공 가치 → 빠른 시작 흐름이 첫 화면에 남아 있는지 먼저 확인합니다.

## 빠른 상태 문장 템플릿

`랜딩 상태: 이 저장소는 <대상 사용자>를 위해 <핵심 가치>를 먼저 보여주고, 첫 행동은 <검증 명령/문서>로 이어집니다.`

English mirror:

`Landing status: this repository leads with <audience> + <core value>, then routes the first action to <validation command/doc>.`

## 예시 / Example

`랜딩 상태: 이 저장소는 한국어 기반 빌더를 위해 검증 가능한 스킬 큐레이션 가치를 먼저 보여주고, 첫 행동은 python3 templates/scripts/validate_template.py 실행으로 이어집니다.`

## 점검 규칙 / Review rule

- 첫 화면에서 프로젝트 소개가 보이는가?
- 대상 사용자가 바로 드러나는가?
- 가치 설명이 운영 규칙보다 먼저 오는가?
- 빠른 시작이나 다음 문서가 첫 화면 안에 있는가?
