# README 프로젝트 첫 화면 개요 / README first-screen project overview

README 상단을 프로젝트 소개 우선 구조로 유지하기 위한 한 페이지 요약입니다.
기여 규칙·운영 가이드는 아래로 내리고, 첫 화면에서는 프로젝트 소개·대상 사용자·제공 가치·대표 예시·빠른 시작이 먼저 보이도록 정리합니다.

English mirror:
A one-page summary for keeping the README top intro-first.
Governance-heavy detail moves lower; the first screen should lead with project overview, audience, value, featured examples, and quick start.

## 첫 화면에서 먼저 보여줄 것 / What the first screen should show first

1. **프로젝트 소개 / Project overview** — 이 저장소가 무엇을 하고 왜 필요한지 한 줄로 설명
2. **대상 사용자 / Who it helps** — 누가 바로 이 저장소의 이득을 보는지 명시
3. **제공 가치 / Immediate value** — 첫 방문자가 즉시 얻는 실행/검증/기여 가치 제시
4. **대표 예시와 카테고리 / Featured examples and categories** — 탐색 시작점을 빠르게 고르게 함
5. **빠른 시작 / Quick start** — 첫 명령과 다음 문서를 같은 화면에 둠

## 아래로 내릴 것 / What should move lower

- 장문의 운영 규칙
- 큐레이션 정책 세부 기준
- 저장소 구조 전체 설명
- 역할별 상세 운영 동선

## 상단 수정 후 확인 질문 / Post-edit checks
