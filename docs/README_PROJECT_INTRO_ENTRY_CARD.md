# README 프로젝트 소개 엔트리 카드 / Project intro entry card

README 첫 화면을 손볼 때 가장 먼저 지켜야 할 최소 진입 카드입니다.
English mirror: This is the minimum entry card to preserve before changing the first README screen.

## 첫 화면 20초 점검 / 20-second first-screen check

1. **프로젝트 소개 / Project intro** — 이 저장소가 무엇을 하는지 첫 두세 줄 안에 보이는가?
2. **대상 사용자 / Audience** — 누가 이 저장소를 먼저 보면 좋은지 바로 드러나는가?
3. **제공 가치 / Immediate value** — 검증/기여/탐색 중 무엇을 바로 얻는지 첫 화면에서 보이는가?
4. **첫 행동 / First action** — `python3 templates/scripts/validate_template.py`와 다음 문서가 눈에 띄는가?

## 한 줄 기준 / One-line rule

README 첫 화면은 링크를 많이 나열하는 곳이 아니라, 프로젝트 소개 → 대상 사용자 → 제공 가치 → 첫 행동을 먼저 납득시키는 진입 화면이어야 합니다.
English mirror: The first README screen should sell the repo intro, audience, value, and first action before it expands into long navigation.
