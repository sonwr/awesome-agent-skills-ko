- 첫 검증 명령은 `python3 templates/scripts/validate_template.py`를 그대로 유지한다.
- 다음 문서는 `examples/quickstart.md` 또는 `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md`처럼 바로 이어지는 한 개를 우선 노출한다.
