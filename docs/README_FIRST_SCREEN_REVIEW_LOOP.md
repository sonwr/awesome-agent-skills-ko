# README 첫 화면 리뷰 루프 / README first-screen review loop

## 목적 / Purpose
README 상단을 바꾼 뒤에도 프로젝트 소개 → 대상 사용자 → 제공 가치 → 대표 경로가 첫 화면에서 유지되는지 빠르게 재점검하는 문서입니다.
This doc helps maintainers quickly recheck that the README first screen still keeps the project intro, audience, immediate value, and featured paths visible after edits.

## 3-step loop / 3단계 루프
1. README 상단 80줄 안에서 프로젝트 소개와 한국어/영어 기본 pitch가 남아 있는지 확인합니다.
2. 첫 행동(검증 명령, 대표 예시, 다음 문서)이 첫 화면에서 바로 보이는지 확인합니다.
3. 운영 규칙과 기여 세부 사항은 아래 문서로 내려가 있는지 확인합니다.

## 빠른 점검 질문 / Quick review questions
- 프로젝트가 무엇을 하는지 첫 20줄 안에서 이해되는가?
- 누가 먼저 보면 좋은지 첫 화면에서 드러나는가?
- 바로 실행할 첫 명령과 다음 문서가 이어지는가?
- 운영/기여 정보가 랜딩을 압도하지 않는가?
