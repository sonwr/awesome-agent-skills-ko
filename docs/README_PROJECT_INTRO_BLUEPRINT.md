# README 소개형 상단 설계 청사진 / README intro-first blueprint

README 첫 화면은 프로젝트 소개형 랜딩 페이지처럼 동작해야 합니다.
English mirror: The README first screen should behave like a project-introduction landing page.

## 상단에 먼저 보여줄 것 / What should appear first

1. 프로젝트 소개 / Project overview
   - `무엇을 하나요? / What does it do?`
   - `왜 필요한가요? / Why does it matter?`
2. 대상 사용자 / Who this is for
3. 제공 가치 / What you get
4. 대표 카테고리와 예시 / Featured categories and examples
5. 빠른 시작 / Quick start

## 뒤로 미룰 것 / What should move lower

- 상세 운영 규칙 / detailed governance rules
- 큐레이션 정책 전문 / full curation policy
- 장기 로드맵 / long-term roadmap
- 저장소 구조 상세 / full repository structure

## English mirror

Keep the first screen focused on project introduction, audience fit, value, examples, and the first runnable command. Move contribution guardrails and governance-heavy material to lower sections or dedicated docs.
