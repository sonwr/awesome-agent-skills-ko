# README 프로젝트 스타트히어 카드 / README project start-here card

README 첫 화면에서 프로젝트 소개 우선 구조를 유지하기 위한 한 페이지 기준 문서입니다.

## 한국어 기준 / Korean-first card

첫 화면에서 최소한 아래 다섯 가지를 순서대로 보이게 유지합니다.

1. **프로젝트 소개** — 이 저장소가 무엇을 모으고 왜 존재하는지 한 줄로 설명
2. **대상 사용자** — 누가 먼저 읽으면 좋은지 명시
3. **제공 가치** — 첫 화면만 읽어도 무엇을 바로 얻는지 설명
4. **대표 예시/카테고리** — quickstart, PR 증빙, 정보구조 문서를 먼저 연결
5. **빠른 시작** — 첫 검증 명령과 다음 문서를 같은 화면에서 제공

## 첫 화면 카드 문장 예시 / First-screen card copy examples

- 프로젝트 소개 — 한국어 기반 빌더를 위한 에이전트 스킬 큐레이션 + 실행 가능한 템플릿 모음
- 대상 사용자 — 한국어 기본 흐름으로 탐색·검증·기여를 빠르게 시작하려는 개인/팀
- 제공 가치 — 첫 검증 명령, 다음 문서, 첫 PR 증빙 경로를 한 번에 찾게 함
- 대표 예시 — `examples/quickstart.md`, `examples/pr-evidence-mini-walkthrough.md`
- 빠른 시작 — `python3 templates/scripts/validate_template.py` → `examples/quickstart.md`
