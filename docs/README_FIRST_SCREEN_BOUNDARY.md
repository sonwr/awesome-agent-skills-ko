# README first-screen boundary / README 첫 화면 경계

README 상단을 고칠 때 첫 화면이 과도하게 길어지지 않도록 확인하는 간단한 기준입니다.

## 핵심 질문 / Core questions

1. **프로젝트 소개가 먼저 보이나? / Does the project intro appear first?**
2. **대상 사용자와 제공 가치가 첫 화면 안에 남아 있나? / Do audience and value stay on the first screen?**
3. **운영 규칙이 소개 블록을 밀어내고 있지 않나? / Are governance details pushing out the intro block?**

## 한 줄 원칙 / One-line rule

프로젝트 소개 → 대상 사용자 → 제공 가치 → 빠른 시작 순서를 잃지 않고, 운영 문서는 아래 섹션이나 별도 문서로 내립니다.
