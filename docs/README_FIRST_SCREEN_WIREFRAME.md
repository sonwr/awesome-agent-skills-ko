# README 첫 화면 와이어프레임 / README first-screen wireframe

README 상단을 **프로젝트 소개 우선**으로 유지하기 위한 간단한 와이어프레임입니다.
English mirror: A compact wireframe for keeping the README top project-intro-first.

## 상단 1스크린 구조 / First-screen structure

1. **프로젝트 소개 / Project intro** — 이 저장소가 무엇을 하는지 한 줄로 설명
2. **대상 사용자 / Who it helps** — 누구에게 맞는지 즉시 판단 가능하게 정리
3. **제공 가치 / What you get** — 첫 화면에서 바로 얻는 가치 2~3개
4. **대표 예시·카테고리 / Featured examples and categories** — 어디부터 눌러야 할지 보여주기
5. **빠른 시작 / Quick start** — 첫 명령과 다음 문서를 함께 노출

English mirror:
1. **Project intro** — one-line explanation of what this repo does.
2. **Who it helps** — make the target audience obvious immediately.
3. **What you get** — show 2-3 immediate benefits on the first screen.
4. **Featured examples and categories** — point to the first useful paths.
5. **Quick start** — keep the first command and next doc together.

## 아래로 미루는 내용 / What moves lower

- 긴 운영 규칙 / long governance rules
- 세부 체크리스트 / detailed checklists
- 감사용 네비게이션 묶음 / audit-heavy navigation bundles
- 반복 설명 / repeated explanatory blocks

English mirror:
- long governance rules
- detailed checklists
- audit-heavy navigation bundles
- repeated explanatory blocks

## 유지 점검 질문 / Maintenance prompts

- 첫 1스크린만 읽어도 저장소의 목적이 보이는가?
- README 상단에서 첫 검증 명령과 다음 문서를 바로 찾을 수 있는가?
- 운영/기여 세부 규칙이 소개보다 먼저 나오지 않는가?

English mirror:
- Can a visitor understand the repo purpose from the first screen alone?
- Can they find the first validation command and next doc immediately?
- Do governance details stay below the intro/value area?
