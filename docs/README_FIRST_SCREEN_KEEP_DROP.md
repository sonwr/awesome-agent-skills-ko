# README 첫 화면 유지/이관 카드 / README first-screen keep/drop card

## 한국어 기준 / Korean-first rule

첫 화면에서는 프로젝트 소개, 대상 사용자, 제공 가치, 대표 예시/빠른 시작만 남기고 운영 세부 규칙은 아래나 별도 문서로 이관합니다.

### 상단에 남길 것 / Keep on the first screen
- 프로젝트가 무엇인지 한 줄로 설명하는 소개
- 누가 이 저장소를 먼저 보면 좋은지
- 지금 바로 실행할 첫 검증 명령
- 대표 예시와 다음 문서 1~3개

### 아래로 내릴 것 / Move lower
- 운영 세부 규칙
- 장문의 기여 정책
- 반복 설명이 많은 큐레이션 원칙
- 심화 FAQ와 유지보수 절차
