# README 프로젝트 첫 이슈 경로 / README project first-issue path

## 목적 / Purpose
README 첫 화면에서 "첫 PR"뿐 아니라 "첫 이슈"로 진입하는 사용자도 바로 길을 찾게 하기 위한 보조 문서입니다.

## 첫 이슈로 들어오는 사람에게 필요한 것 / What first-issue visitors need
- 프로젝트 소개가 먼저 보여야 함
- 어떤 종류의 이슈를 열어야 하는지 빠르게 보여야 함
- 재현/검증 링크가 이슈 전에 보여야 함
- 운영 규칙은 첫 화면 하단이나 별도 문서로 내려야 함

## README 연결 위치 / README placement
- 프로젝트 소개 다음이 아니라, 추천 시작 경로나 기여 준비 블록에서 연결
- 첫 화면 소개 흐름(소개 → 대상 사용자 → 가치 → 예시/빠른 시작)을 깨지 않도록 보조 링크로 유지
