# README 첫 화면 재점검 / README first-screen recheck

README 상단을 건드린 뒤 intro-first 구조가 아직 유지되는지 30초 안에 다시 확인하는 카드입니다.
English mirror: A 30-second recheck card for confirming that the README still keeps an intro-first landing flow after edits.

## 재점검 순서 / Recheck order

1. **프로젝트 소개가 첫 화면에 남아 있는가? / Does the project intro stay on the first screen?**
2. **대상 사용자와 제공 가치가 소개 바로 아래에 보이는가? / Do audience and value stay directly under the intro?**
3. **첫 검증 명령과 다음 문서가 같은 화면에 남아 있는가? / Do the first validation command and next docs stay visible together?**
4. **운영 규칙은 아래 문단이나 별도 문서로 내려갔는가? / Did governance detail stay lower in the README or in dedicated docs?**

## 빠른 통과 기준 / Fast pass signal

- 소개 → 대상 사용자 → 가치 → 빠른 시작 흐름이 첫 화면에서 끊기지 않으면 통과입니다.
- 영어 미러는 한국어 기본 흐름을 방해하지 않는 선에서 짧게 유지합니다.
