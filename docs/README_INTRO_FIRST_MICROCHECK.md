# README intro-first microcheck

README를 크게 흔들지 않고도 intro-first 구조를 점검할 때 쓰는 초간단 체크리스트입니다.

## 한국어

- 첫 화면에서 **프로젝트가 무엇인지** 3줄 안에 보이는가?
- 첫 클릭 전에 **어디서 시작할지** 바로 보이는가?
- 기여자와 탐색자가 같은 링크 더미를 보지 않도록 경로가 분리되어 있는가?
- validator를 돌리기 전에도 README 상단만 읽고 다음 행동이 떠오르는가?

## English

- Can a first-time visitor understand the project in three lines?
- Is the first action obvious before they scroll?
- Are contributor and explorer paths separated early?
- Does the top section still point to a runnable validation step?
