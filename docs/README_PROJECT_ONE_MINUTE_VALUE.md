# README 프로젝트 1분 가치 카드 / README project one-minute value card

README 상단을 고칠 때, 첫 1분 안에 방문자가 **이 저장소가 무엇인지 / 누구에게 맞는지 / 지금 무엇을 해야 하는지**를 바로 이해하게 만드는 기준 카드입니다.

## 한국어 기준 / Korean-first card

- **프로젝트 소개 / Project intro** — 한국어 기본 에이전트 스킬 큐레이션 + 실행 가능한 템플릿 저장소
- **대상 사용자 / Who it helps** — 탐색·검증·기여를 빠르게 시작하려는 개인/팀
- **즉시 가치 / Immediate value** — 첫 검증 명령, 다음 문서, 첫 PR 증빙 경로를 한 화면에서 확인
- **대표 예시 / Featured examples** — `examples/quickstart.md`, `examples/pr-evidence-mini-walkthrough.md`, `docs/README_FIRST_SCREEN_CHECKLIST.md`
- **빠른 시작 / Quick start** — `python3 templates/scripts/validate_template.py` -> `examples/quickstart.md`
- **운영 문서 핸드오프 / Governance handoff** — `CONTRIBUTING.md`, `docs/README_FAST_PATHS.md`, `docs/CURATION_POLICY.md`

## English mirror

- **Project intro** — a Korean-first curation repo for agent skills plus runnable templates
- **Who it helps** — individuals and teams who want a fast path for discovery, validation, and contribution
- **Immediate value** — show the first validation command, next docs, and first-PR evidence path on one screen
- **Featured examples** — `examples/quickstart.md`, `examples/pr-evidence-mini-walkthrough.md`, `docs/README_FIRST_SCREEN_CHECKLIST.md`
- **Quick start** — `python3 templates/scripts/validate_template.py` -> `examples/quickstart.md`
- **Governance handoff** — `CONTRIBUTING.md`, `docs/README_FAST_PATHS.md`, `docs/CURATION_POLICY.md`

## 유지 규칙 / Maintenance rule

README 상단을 바꾼 뒤에는 이 카드와 실제 상단이 같은 순서를 유지하는지 확인합니다:

1. 프로젝트 소개
2. 대상 사용자
3. 제공 가치
4. 대표 예시/카테고리
5. 빠른 시작
6. 운영 문서 핸드오프
