# README 프로젝트 소개 스코어카드 / README project intro scorecard

README 상단이 프로젝트 소개 우선 구조를 지키는지 빠르게 점검하는 한/영 기준표입니다.
English mirror: A quick bilingual scorecard for checking whether the README still leads with project intro before governance details.

## 한국어 기준 / Korean-first scorecard
- **프로젝트 소개가 먼저 보이는가? / Does the project intro appear first?** 첫 화면 초반에서 저장소의 목적이 바로 드러나야 합니다.
- **대상 사용자와 제공 가치가 이어지는가? / Do audience and value follow immediately?** 소개 다음에 누구를 돕는지와 왜 필요한지를 보여줘야 합니다.
- **대표 예시와 빠른 시작이 붙어 있는가? / Are examples and quick start adjacent?** 첫 행동과 다음 문서를 같은 화면에서 찾게 해야 합니다.
- **운영 문서는 아래로 내려갔는가? / Did governance move lower?** CONTRIBUTING/운영 정책은 랜딩 블록 아래 handoff로 남겨야 합니다.

## English mirror
- **Project intro first** — the first screen should explain what the repo is for before it explains governance.
- **Audience and value next** — visitors should see who it helps and why it matters right after the intro.
- **Examples plus quick start together** — the first command and next docs should stay on the same screen.
- **Governance lower** — contribution and operations rules should remain a handoff below the landing block.

## 유지 규칙 / Maintenance rule
README 상단을 고칠 때는 소개 → 대상 사용자 → 제공 가치 → 대표 예시/빠른 시작 → 운영 핸드오프 순서를 깨지 않습니다.
English mirror: Preserve the order intro -> audience -> value -> featured examples/quick start -> governance handoff whenever the README landing area changes.
