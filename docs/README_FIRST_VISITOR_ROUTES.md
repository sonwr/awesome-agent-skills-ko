# README 첫 방문 경로 / README first-visitor routes

README 소개 우선 구조에서 처음 방문자가 15초 안에 갈림길을 고를 수 있게 돕는 짧은 안내입니다.
English mirror: A short guide that helps first-time visitors pick the right intro-first route within 15 seconds.

## 한국어 기준 / Korean-first routes

- **탐색 먼저 / Explore first** — 프로젝트 소개를 먼저 읽고 `docs/PROJECT_OVERVIEW.md`로 넘어갑니다.
- **바로 실행 / Validate now** — `python3 templates/scripts/validate_template.py`를 실행한 뒤 `examples/quickstart.md`를 엽니다.
- **바로 기여 / Contribute now** — `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md`와 `examples/pr-evidence-mini-walkthrough.md`를 바로 엽니다.
- **운영 점검 / Audit the structure** — `docs/README_FAST_PATHS.md`, `docs/README_FIRST_SCREEN_CHECKLIST.md`를 열어 랜딩 구조를 점검합니다.

## English mirror

- **Explore first** — read the project intro, then continue with `docs/PROJECT_OVERVIEW.md`.
- **Validate now** — run `python3 templates/scripts/validate_template.py`, then open `examples/quickstart.md`.
- **Contribute now** — jump straight to `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md` and `examples/pr-evidence-mini-walkthrough.md`.
- **Audit the structure** — use `docs/README_FAST_PATHS.md` and `docs/README_FIRST_SCREEN_CHECKLIST.md` to review the landing flow.
