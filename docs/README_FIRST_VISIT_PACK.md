# README 첫 방문 스타터 팩 / README first-visit pack

README 상단을 프로젝트 소개 우선 구조로 유지할 때, **처음 방문한 사람이 60초 안에 어디로 가야 하는지**를 묶어서 보여주는 문서입니다.

## 첫 60초에 볼 것 / What to open in the first 60 seconds

1. `README.md` 상단 — 프로젝트 소개, 대상 사용자, 제공 가치, 빠른 시작
2. `examples/quickstart.md` — 첫 복붙 명령과 실행 흐름
3. `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md` — 첫 PR 전 최소 증빙 규칙
4. `examples/pr-evidence-mini-walkthrough.md` — PR 코멘트 예시

- **탐색형 / Explorer** — `README.md` → `docs/PROJECT_OVERVIEW.md` → `docs/README_FEATURED_CATEGORY_MAP.md`

- README 상단이 너무 운영 문서 중심으로 무거워질 때
