# README intro-first 대상 사용자 증빙 루프 / README intro-first audience proof loop

## 한국어 기준 / Korean-first rule

README 첫 화면을 손볼 때는 소개 문장 바로 아래에 **대상 사용자 → 첫 검증 명령 → 다음 문서**가 같은 시야에 남는지 먼저 확인합니다.

### 짧은 점검 순서 / Short check order
- 소개 문장만 읽어도 저장소 목적이 보이는가?
- 바로 다음 줄에서 누가 시작하면 좋은지 보이는가?
- 첫 검증 명령과 다음 문서가 바로 이어지는가?
- 운영/정책 문서는 그 아래로 내려가 있는가?

## English mirror

When editing the README first screen, verify that **audience -> first validation command -> next doc** stays visible directly under the intro before expanding governance details.
