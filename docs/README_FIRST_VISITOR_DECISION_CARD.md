# README 첫 방문 결정 카드 / README first-visitor decision card

README 첫 화면에서 방문자가 바로 다음 행동을 고를 수 있게 돕는 짧은 기준 카드입니다.

## 한국어 기준 / Korean-first rule
- **탐색 먼저 / Explore first** — 저장소 성격을 30초 안에 파악하려면 `## 프로젝트 소개 / Project overview`와 `## 대상 사용자 / Who this is for`를 먼저 읽습니다.
- **바로 검증 / Validate now** — 실행 가능성을 바로 확인하려면 `python3 templates/scripts/validate_template.py`를 먼저 실행합니다.
- **바로 기여 / Contribute now** — 첫 PR 준비라면 `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md`와 `CONTRIBUTING.md`로 이동합니다.
- **구조 점검 / Audit the landing** — README 상단이 소개 우선 구조를 지키는지 보려면 `docs/README_PROJECT_FIRST_SCREEN_OVERVIEW.md`와 `docs/README_FIRST_SCREEN_JUMP_LIST.md`를 확인합니다.

## English mirror
- **Explore first** — Read `## 프로젝트 소개 / Project overview` and `## 대상 사용자 / Who this is for` first when you want the repo value in under 30 seconds.
- **Validate now** — Run `python3 templates/scripts/validate_template.py` first when you want proof that the repo is runnable.
- **Contribute now** — Jump to `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md` and `CONTRIBUTING.md` when you are preparing the first PR.
- **Audit the landing** — Review `docs/README_PROJECT_FIRST_SCREEN_OVERVIEW.md` and `docs/README_FIRST_SCREEN_JUMP_LIST.md` when checking whether the README still stays intro-first.
