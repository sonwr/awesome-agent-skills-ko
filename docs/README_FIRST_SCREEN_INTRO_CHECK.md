# README 첫 화면 소개 점검 카드 / First-screen intro check

README 상단을 수정한 뒤 아래 3가지를 먼저 확인합니다.

1. **프로젝트 소개 / Project intro** — 첫 화면에 저장소의 목적이 한 줄 이상 남아 있는가?
2. **대상 사용자 / Audience** — 누가 이 저장소를 먼저 보면 좋은지 바로 보이는가?
3. **첫 행동 / First action** — 검증 명령과 다음 문서가 첫 화면에서 이어지는가?

이 카드의 목적은 운영 링크를 더 추가하는 것이 아니라, README 첫 화면에서 프로젝트 소개가 사라지지 않게 막는 것입니다.
