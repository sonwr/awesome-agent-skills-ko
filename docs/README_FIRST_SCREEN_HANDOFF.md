# README 첫 화면 handoff 카드 / README first-screen handoff card

## 목적 / Purpose
README 첫 화면에서 프로젝트 소개 → 대상 사용자 → 제공 가치 → 대표 경로 → 빠른 시작이 끊기지 않게 이어지는지 빠르게 점검합니다.

## 30초 확인 순서 / 30-second check order
1. 프로젝트 소개가 첫 화면 초반에 보이는가?
2. 대상 사용자 문장이 소개 바로 아래에서 이어지는가?
3. 제공 가치와 대표 카테고리/예시가 스크롤 과다 없이 보이는가?
4. 빠른 시작 명령과 다음 문서가 즉시 이어지는가?
5. 운영/정책 문서는 그 다음 레이어로 내려갔는가?

## handoff 문장 / Handoff sentence
`README 첫 화면은 프로젝트 소개, 대상 사용자, 가치, 대표 경로, 빠른 시작을 먼저 보여주고 운영 문서는 아래 레이어로 넘깁니다.`

## 실패 신호 / Failure signal
첫 화면 안에서 프로젝트 설명보다 운영 규칙 링크가 먼저 눈에 들어오면 intro-first 구조가 약해진 것입니다.
