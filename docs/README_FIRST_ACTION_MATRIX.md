# README 첫 행동 매트릭스 / README first-action matrix

README 상단을 프로젝트 소개 우선 구조로 유지하면서도, 방문자 유형별 **첫 행동 / 다음 문서 / 기대 결과**를 한 장에서 빠르게 확인하는 보조 문서입니다.
English mirror: A compact matrix for checking each visitor's first action, next doc, and expected outcome without breaking the intro-first README landing flow.

## 한국어 기준 / Korean-first matrix

- **탐색형 / Explorer** — 첫 행동: `프로젝트 소개 / Project overview` 읽기 → 다음 문서: `examples/quickstart.md` → 기대 결과: 저장소 가치와 대표 예시를 1분 안에 파악
- **기여형 / Contributor** — 첫 행동: `python3 templates/scripts/validate_template.py` 실행 → 다음 문서: `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md` → 기대 결과: 첫 PR 증빙 형식까지 바로 연결
- **운영형 / Operator** — 첫 행동: `docs/README_FIRST_SCREEN_CHECKLIST.md` 열기 → 다음 문서: `docs/README_FAST_PATHS.md` → 기대 결과: 소개 우선 IA와 운영 handoff 위치를 빠르게 점검

## English mirror

- **Explorer** — First action: read `Project overview` -> Next doc: `examples/quickstart.md` -> Expected result: understand repo value and featured examples within a minute
- **Contributor** — First action: run `python3 templates/scripts/validate_template.py` -> Next doc: `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md` -> Expected result: land on the first PR evidence format quickly
- **Operator** — First action: open `docs/README_FIRST_SCREEN_CHECKLIST.md` -> Next doc: `docs/README_FAST_PATHS.md` -> Expected result: confirm the intro-first IA and governance handoff location quickly

## 사용할 때 / When to use it

- README 상단 80~140줄을 손볼 때
- 역할별 시작 문장을 더 압축해야 할 때
- 소개/가치/빠른 시작 뒤에 무엇이 와야 하는지 빠르게 합의할 때

- When editing the first 80-140 README lines
- When compressing role-based first-action copy
- When aligning what should happen right after intro/value/quick-start blocks
