# README first-visit decision card

README 첫 화면에서 방문자가 **무엇을 먼저 할지 15초 안에 고르게 만드는 기준 카드**입니다.
English mirror: A compact card for helping first-time visitors pick the right first action from the README landing area within 15 seconds.

## 목적 / Purpose

- 소개 우선 구조를 유지합니다.
- 첫 행동(탐색 / 검증 / 기여 / 운영 점검)을 바로 고르게 합니다.
- 운영 문서가 프로젝트 소개 위로 올라오는 드리프트를 막습니다.

English mirror:
- Preserve the intro-first landing structure.
- Help visitors choose the first action quickly.
- Prevent governance-heavy drift above the project story.

## 15초 질문 / 15-second questions

1. **이 저장소가 나와 맞는가? / Is this repo for me?**
2. **지금 무엇을 해야 하나? / What should I do now?**
3. **다음 문서는 무엇인가? / What should I open next?**

## 권장 첫 행동 / Recommended first actions

- **탐색 / Explore** — `프로젝트 소개 / Project overview`
- **검증 / Validate** — `python3 templates/scripts/validate_template.py`
- **기여 / Contribute** — `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md`
- **운영 점검 / Audit** — `docs/README_FAST_PATHS.md`

## 유지 규칙 / Maintenance rule

README 상단을 수정한 뒤에는 다음을 확인합니다.
English mirror: After editing the README top, confirm the following.

- 소개 / 대상 사용자 / 제공 가치가 첫 화면에 남아 있는가?
- 빠른 시작 명령이 첫 화면에 남아 있는가?
- 운영/정책 링크가 소개보다 위로 올라오지 않았는가?
- `python3 templates/scripts/validate_template.py`가 계속 통과하는가?
