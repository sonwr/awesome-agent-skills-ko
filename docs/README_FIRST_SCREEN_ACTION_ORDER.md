# README_FIRST_SCREEN_ACTION_ORDER

README 첫 화면은 소개 다음에 바로 **대상 사용자 -> 첫 명령 -> 다음 문서** 순서를 보여줘야 합니다.

짧은 점검 순서:
1. 소개 문장 바로 아래에 대상 사용자 약속이 남아 있는가?
2. 첫 검증 명령이 첫 화면에서 복붙 가능한가?
3. 다음 문서(`examples/quickstart.md`)가 같은 화면에서 바로 보이는가?
4. 운영/정책 문서가 이 묶음 위로 올라오지 않았는가?

English mirror:
Keep the README first screen in this order right after the intro: **audience -> first command -> next doc**.
Check that the audience promise stays visible, the validation command is copyable, the next doc stays on the same screen, and governance links do not jump above that bundle.
