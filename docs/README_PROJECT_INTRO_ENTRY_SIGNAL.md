# README 프로젝트 소개 진입 신호 / README project intro entry signal

## 한국어 기준 / Korean-first signal

README 상단은 먼저 "이 저장소가 무엇인지"를 말해야 한다. 첫 화면에서 다음 질문 세 가지가 즉시 보여야 한다.

- 어떤 종류의 저장소인가? / What kind of repo is this?
- 누가 여기서 시작해야 하나? / Who should start here?
- 지금 바로 무엇을 해야 하나? / What should I do now?

운영/거버넌스 링크는 소개 블록 아래에서 이어지게 두고, 소개 문장보다 먼저 나오지 않게 유지한다.

## English mirror

The README should first say what the repository is. The first screen should answer these three questions immediately.

- What kind of repo is this?
- Who should start here?
- What should I do now?

Keep governance and operations links below the intro block so they follow the first-screen project explanation instead of replacing it.
