# README intro-first 종료 체크리스트 / README intro-first exit checklist

README 상단을 고친 뒤 마지막으로 확인하는 짧은 체크리스트입니다.
This is a short last-pass checklist for README landing edits.

## 확인 항목 / Checks

1. **프로젝트 소개 우선 / Project intro first** — 첫 화면에서 저장소가 무엇을 하는지 바로 보이는가?
2. **대상 사용자 노출 / Audience visible** — 누가 이 저장소를 먼저 보면 좋은지 상단에서 설명되는가?
3. **가치 먼저 / Value before governance** — 운영 규칙보다 사용 가치와 시작 경로가 먼저 보이는가?
4. **첫 행동 명확 / First action clear** — 검증 명령이나 첫 문서가 상단에서 바로 드러나는가?
5. **운영 문서 분리 / Governance moved lower** — CONTRIBUTING/정책/세부 운영 안내가 랜딩 블록 아래로 내려가 있는가?

## 한 줄 판단 / One-line decision

- 위 다섯 항목이 모두 보이면 intro-first 유지 성공.
- 하나라도 흐려지면 README 상단을 다시 줄이고 프로젝트 소개를 앞으로 당깁니다.
