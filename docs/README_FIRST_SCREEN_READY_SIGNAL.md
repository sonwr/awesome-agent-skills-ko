# README 첫 화면 준비 신호 / README first-screen ready signal

README 상단을 손본 뒤 아래 네 가지가 모두 보이면 첫 화면 준비 상태로 봅니다.

1. **프로젝트 소개 / Project intro** — 저장소가 무엇을 하는지 첫 화면에서 바로 보인다.
2. **대상 사용자 / Who it helps** — 누가 먼저 읽어야 하는지 첫 화면에서 알 수 있다.
3. **제공 가치 / Immediate value** — 단순 링크 모음이 아니라 실행·검증·기여 경로가 드러난다.
4. **첫 행동 / First action** — 검증 명령과 다음 문서가 첫 화면 안에서 이어진다.

하나라도 빠지면 운영 문서나 긴 링크 블록보다 소개·가치·빠른 시작을 먼저 올립니다.

## 짧은 판정 문장 / Short decision line

- **준비됨 / Ready:** 소개 → 대상 사용자 → 가치 → 첫 행동이 첫 화면에 남아 있다.
- **보류 / Hold:** 운영 정보가 먼저 보이거나 첫 행동 경로가 첫 화면에서 끊긴다.
