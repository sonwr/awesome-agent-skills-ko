# README 첫 1분 결과 카드 / README first-minute outcomes card

README 첫 화면이 프로젝트 소개 우선 구조를 유지하는지 빠르게 점검할 때 쓰는 짧은 기준 문서입니다.
Use this short guide to verify that the README keeps a project-intro-first landing flow.

## 한국어 기준 / Korean-first outcomes

- **1분 안에 프로젝트를 이해할 수 있어야 함** — 저장소가 무엇을 하는지, 누구를 위한지, 왜 필요한지가 첫 화면에서 드러나야 합니다.
- **1분 안에 첫 행동을 고를 수 있어야 함** — 탐색, 검증, 기여, 운영 점검 중 하나를 바로 선택할 수 있어야 합니다.
- **1분 안에 다음 문서를 열 수 있어야 함** — `examples/quickstart.md`, `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md`, `docs/README_FAST_PATHS.md` 중 적어도 하나로 자연스럽게 이어져야 합니다.

## English mirror

- **Understand the repo within 1 minute** — the first screen should reveal what the repo does, who it serves, and why it matters.
- **Choose the first action within 1 minute** — visitors should be able to pick explore, validate, contribute, or audit immediately.
- **Open the next doc within 1 minute** — the landing area should hand off naturally to `examples/quickstart.md`, `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md`, or `docs/README_FAST_PATHS.md`.

## 유지 규칙 / Maintenance rule

README 상단을 바꿀 때는 이 문서의 세 기준이 계속 첫 화면 안에서 보이는지 확인합니다.
When you edit the README top section, keep all three outcomes visible within the first screen.
