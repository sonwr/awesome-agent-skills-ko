# README 사용자 여정 / README user journeys

README 상단을 프로젝트 소개 우선 구조로 유지하기 위해, 방문자 유형별로 어떤 섹션을 먼저 열어야 하는지 정리한 문서입니다.
English mirror: This doc keeps the README intro-first by mapping which sections each visitor type should open first.

## 탐색형 방문자 / Explorer journey

- 1단계: `README.md`의 프로젝트 소개 → 대상 사용자 → 제공 가치를 읽습니다.
- 2단계: 대표 카테고리와 활용 시나리오를 보고 저장소 적합성을 30초 안에 판단합니다.
- 3단계: `examples/quickstart.md`로 이동해 첫 실행 명령을 복붙합니다.

English mirror:
- Step 1: read the project overview, audience, and value sections in `README.md`.
- Step 2: scan featured categories and use cases to decide fit within 30 seconds.
- Step 3: jump to `examples/quickstart.md` for the first copy-paste command.

## 기여형 방문자 / Contributor journey

- 1단계: `README.md`의 빠른 시작 한눈에 보기와 3단계 시작 경로를 봅니다.
- 2단계: `python3 templates/scripts/validate_template.py`를 실행합니다.
- 3단계: `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md`와 `examples/pr-evidence-mini-walkthrough.md`를 열어 최소 PR 증빙 형식을 맞춥니다.

English mirror:
- Step 1: read the quick-start-at-a-glance and 3-step start path in `README.md`.
- Step 2: run `python3 templates/scripts/validate_template.py`.
- Step 3: open `docs/BILINGUAL_CONTRIBUTION_CHECKLIST.md` and `examples/pr-evidence-mini-walkthrough.md` to match the minimum PR evidence format.

## 운영형 방문자 / Operator journey

- 1단계: `docs/PROJECT_ENTRY_PATHS.md`와 `docs/README_INFORMATION_ARCHITECTURE.md`를 읽습니다.
- 2단계: `docs/README_FIRST_SCREEN_CHECKLIST.md`와 이 문서로 README 상단 정보구조가 유지되는지 확인합니다.
- 3단계: `docs/CURATION_POLICY.md`, `docs/TEMPLATE_STANDARD.md`, `docs/ROADMAP.md`로 운영 기준을 점검합니다.

English mirror:
- Step 1: read `docs/PROJECT_ENTRY_PATHS.md` and `docs/README_INFORMATION_ARCHITECTURE.md`.
- Step 2: use `docs/README_FIRST_SCREEN_CHECKLIST.md` and this document to verify the README top remains intro-first.
- Step 3: review `docs/CURATION_POLICY.md`, `docs/TEMPLATE_STANDARD.md`, and `docs/ROADMAP.md` for governance rules.
